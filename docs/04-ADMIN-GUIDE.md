# دليل المدير والموظفين

## الدخول
`/admin` → البريد وكلمة المرور → إن كان دورك مُلزَماً بالتحقق بخطوتين: رمز التطبيق (6 أرقام). أول مرة تُرشَد لإعداده (انظر `02-MFA.md`).

## الأدوار (الافتراضية)
- **owner (المالك):** كل شيء، يدير الأدوار والموظفين وفرض MFA.
- **manager (مدير):** المنتجات، الطلبات (بما فيها الإلغاء والإرجاع)، الكوبونات، التقارير؛ لا يدير الموظفين.
- **support (دعم):** يرى الطلبات ويؤكدها ويحدّث حالتها حتى الشحن؛ لا يلغي ولا يرى التقارير والكوبونات.
المالك يعدّل صلاحيات كل دور من «الموظفون». لا يستطيع أحد منح صلاحية لا يملكها، ولا تعديل نفسه، ولا إزالة آخر مالك.

## الطلبات
- القائمة مُقسّمة إلى صفحات (25). فلاتر: رقم الطلب، الحالة، الهاتف (يقبل 06…/+212…)، المدينة (بدون حساسية للتشكيل)، التاريخ (بتوقيت الدار البيضاء).
- **تغيير الحالة:** الأزرار تعرض الانتقالات المسموحة لدورك فقط: جديد/بانتظار التأكيد → مؤكد → قيد التجهيز → مشحون → مسلّم.
- **الإلغاء** (قبل الشحن) و**تسجيل الإرجاع** (بعد الشحن/التسليم): من قسم «إلغاء أو إرجاع» في صفحة الطلب. **السبب إلزامي**؛ «سبب آخر» يتطلب ملاحظة.
  - الإلغاء نهائي ويُسجَّل فوراً.
  - الإرجاع: *طلب إرجاع* → *موافقة* أو *رفض (ملاحظة إلزامية)* → *استلام البضاعة* (حينها فقط يصير الطلب «مُرجَع»). إن رفض الزبون الاستلام وعادت البضاعة فعلاً فعّل «البضاعة رجعت فعلاً».
  - الطلب وتفاصيله لا يُحذفان ولا يُعدّلان؛ سجل الإلغاء/الإرجاع لا يُحذف.
- **سجل المرتجعات** (قائمة «المرتجعات والإلغاء»): الطلب، السبب، تاريخ الطلب وتاريخ الإرجاع، الحالة، الموظف المسؤول، الملاحظات.

## التقارير
- **المبيعات = الطلبات المسلّمة حالياً فقط.** الملغاة والمرتجعة منفصلة ولا تدخل فيها. «إجمالي الطلبات» ليس مبيعات.
- الفترة بتاريخ إنشاء الطلب (توقيت الدار البيضاء)؛ بطاقة «سُلّمت خلال الفترة» تستعمل تاريخ التسليم.
- تجميع يومي/أسبوعي/شهري، حسب المدينة، المنتجات الأكثر طلباً (بدون الملغاة/المرتجعة)، ملخص التوصيل والخصومات، الإلغاء والإرجاع حسب السبب.
- **الأرقام إيرادات وليست ربحاً صافياً**: تكلفة الشراء والتشغيل غير مسجلة.
- تظهر لمن يملك `reports.view` فقط.

## المنتجات والصور
- الصور تُصغَّر في المتصفح قبل الرفع (حتى 1600px، WebP) لتسريع الموقع.
- لا تنشر منتجاً بلا صورة واضحة؛ أضف نصاً بديلاً (alt) عند الإمكان.
- رسوم التوصيل: صف لكل مدينة + صف افتراضي. أضف صفاً **لكل تهجئة** عربية تريدها (العربية لا تُطابَق تلقائياً بالفرنسية).

## الأمان اليومي
- لا تشارك حسابك. أبلغ المالك فور فقدان الهاتف (انظر الاسترجاع في `02-MFA.md`).
- إيقاف موظف: «الموظفون» → إيقاف (يسحب صلاحياته فوراً). للحظر الكامل احظر حسابه أيضاً من لوحة Supabase.
- المالك: راجع «سجل التدقيق» دورياً.
